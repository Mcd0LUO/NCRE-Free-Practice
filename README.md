# NCRE 数据库刷题（三级 / 四级）

Node + Vite + React + Tailwind 的本地刷题应用。题库为全国计算机等级考试
（NCRE）三级 / 四级 数据库类历年真题，含配套解析。

仅供个人学习交流使用。

## 启动

```bash
cd ncre-app
npm install          # 首次
npm run dev          # 同时起后端 + 前端
```

- 前端（Vite）：http://127.0.0.1:5180
- 后端（Express）：http://127.0.0.1:5181

Vite 已把 `/api` 与 `/images` 代理到后端，所以只需访问前端 5180。

单起：`npm run dev:server` / `npm run dev:web`
生产构建：`npm run build`（产物在 `dist/`，后端会自动托管它）

每题恰好归属 1 个分类（已校验：0 歧义，100% 覆盖）。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/banks` | 题库列表 + 分类树 |
| GET | `/api/questions?bank=&part=&sec=&kind=&q=&page=&size=&fields=` | 分页筛选题目（默认不含解析，`fields=full` 取全量） |
| GET | `/api/questions/:bank/:id` | 单题全量（解析懒加载的数据源） |
| GET | `/api/search/:bank?q=&kind=` | 全文搜索题干与选项 |
| GET | `/api/marked/:bank` | 已标记的题 |
| POST | `/api/backup` / GET `/api/backups` | 进度备份 |
| GET | `/api/stats/:bank` | 总进度 + 每分类正确率 |
| GET | `/api/wrong/:bank` | 错题列表 |
| GET | `/api/papers/:bank` | 试卷列表 |
| GET | `/api/paper/:bank/:ver/:group` | 单套试卷（含题目） |
| POST | `/api/answer` | 记录作答 |
| POST | `/api/mark` | 收藏/标记 |
| POST | `/api/reset` | 清空进度（`scope: all \| bank`） |

## 性能

- **gzip**：`compression` 中间件，JSON 响应传输体积下降 77-87%
- **数据分层**：列表接口不含 `expl`/`refAnswer`（占单题体积约 50%），
  解析在可见时按 id 单取并缓存
- 列表 100 题：**82.7 KB → 7.6 KB（-90.8%）**
- 服务端查询在内存 Map 上完成，中位 3-4 ms

## 判分规则

- **单选**：字母完全一致
- **多选**：字母集合完全一致得满分；有对无错且库里有部分分规则时得部分分（四级 430 题有）
- **填空**：逐空判定，忽略大小写/空格/全角括号，`mark` 里的多个备选答案任一命中即算对；
  得分 = 满分 × 答对空数 / 总空数
- **设计与应用题**：主观题，自评

判分逻辑在 `src/grading.js`，有 18 条单元测试：`node test-grading.mjs`

## 数据结构

题库**按等级分文件**存放：`server/data/bank_<id>.json`（三级 = `bank_36.json`，
四级 = `bank_42.json`）。一库一文件，编辑或重建只影响单库，git diff 也落在对应等级范围内。
服务端启动时扫描 `bank_*.json`，新增等级只需放入文件，无需改代码。

```jsonc
{
  "id": "42", "name": "四级数据库工程师", "grade": 4, "timeMin": 90,
  "parts":   [ { "id": 1, "name": "操作系统原理-单选题", "sections": [...] } ],
  "questions": [ { "id", "kind", "score", "half", "part", "partName",
                   "sec", "secName", "stem", "options", "letters",
                   "refAnswer", "fills", "expl", "images" } ],
  "papers":  [ { "ver", "group", "date", "sections": [{ "ids": [...] }] } ]
}
```

> 题库文件与图片随仓库一同分发，克隆后即可直接运行。

- `kind`：`single` | `multi` | `fill` | `essay`
- `letters`：正确选项字母（多选去重排序）
- `fills`：`[{ n, alts: [...] }]` 每空的备选答案
- 题干里的图片写成 `[[IMG:文件名]]`，由 `RichText` 渲染为 `/images/文件名`

图片在 `server/data/images/`（322 张，含三级 76 + 四级 246）。

## 访问口令

线上部署带一层登录门。凭据不入库，放在运行目录的 `.env`（权限 600）：

```env
NCRE_USER=admin
NCRE_PASS=<你的口令>
NCRE_SECRET=<随机 64 位十六进制>
```

`NCRE_SECRET` 用于给会话 Cookie 做 HMAC 签名；改了它所有已登录设备会立即失效。
登录成功后服务端下发 `HttpOnly; Secure; SameSite=Lax; Max-Age=30d` 的 Cookie，刷新 / 重开免登；
侧边栏「退出登录」清除。未设置 `NCRE_PASS` 时鉴权自动关闭（本地开发方便）。
未登录时 `/api/*` 与 `/images/*` 一律返回 401。
